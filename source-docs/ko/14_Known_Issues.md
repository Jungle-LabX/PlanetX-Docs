# 알려진 문제

확인된 문제와 현재 대응 상태를 정리합니다. 검증되지 않은 제보를 제품 결함으로 단정해 게시하지 않습니다.

## 상태 정의

| 상태 | 의미 |
|---|---|
| 조사 중 | 제보를 인지했으며 재현 여부를 확인하고 있습니다. |
| 패치 진행 중 | 원인을 파악했고 변경 사항을 구현하거나 검증하고 있습니다. |
| 우회 방법 제공 | 영구 수정 전 사용할 수 있는 복구 절차가 문서화되어 있습니다. |
| 해결됨 | 현재 공개 문서 또는 제품 릴리스에 수정이 포함되었습니다. |

## 문서 포털

| 문제 | 상태 | 현재 대응 |
|---|---|---|
| Mermaid 블록이 원본 코드로 표시됨 | 패치 진행 중 | Mermaid 블록을 테마 대응 SVG로 렌더링했으며 최종 브라우저 검증을 진행하고 있습니다. |
| 하위 문서 화면에서 라이트/다크 모드가 일관되지 않음 | 패치 진행 중 | 전역 Surface, Border, Text, Table, Code, Search, Diagram 토큰을 함께 점검하고 있습니다. |
| 사이드바, 테이블 메타데이터, 목차 글자가 너무 작음 | 패치 진행 중 | 문서 타이포그래피 최소 크기를 높였으며 반응형 화면을 검증하고 있습니다. |
| 내비게이션 이름과 목적지가 일부 일치하지 않음 | 패치 진행 중 | Header, Sidebar, FAQ, Known Issues, Support 경로를 하나의 canonical 내비게이션 정의로 통합하고 있습니다. |

## PlanetX 플러그인

현재 공개할 수 있는 확인된 Runtime 또는 Editor 결함은 없습니다. 제품 이슈는 재현 사례와 영향 범위를 검증한 뒤 이 페이지에 추가합니다.

## 새 문제를 보고하기 전에

1. [문제 해결](/docs/ko/troubleshooting)과 [FAQ](/faq)를 확인합니다.
2. PlanetX와 Unreal Engine 버전을 기록합니다.
3. 정확한 재현 절차와 Editor, PIE, 패키지 빌드 중 어디에서 발생하는지 포함합니다.
4. 안전하게 공유할 수 있는 관련 로그, 진단 결과, 최소 재현 프로젝트 상태를 포함합니다.
